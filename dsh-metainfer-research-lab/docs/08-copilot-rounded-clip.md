# Copilot 外层圆角裁剪与帧交付

## 最小修改

大型内嵌会话容器保留原有尺寸、`overflow: hidden`、内部滚动和输入栏，仅将桌面及移动断点的 `.rl-copilot-native` 外层 `border-radius` 设为 `0`。外观差异是方角，不删除、截断或迁移会话内容，也不以原生视图替代内嵌功能。

## 验证依据与边界

在一个 Windows/Chromium 实机环境、2560×1392 CSS 视口和 DPR 1.5 下，对同一已有会话进行了圆角→方角→圆角→方角→圆角对照。圆角阶段名义窗口内的 rAF 间隔交付约为 5–5.7 次/秒，P50 约 183 ms；两轮方角阶段在过渡窗口后均达到 60 次/秒，P50 约 16.7 ms。安装后同一会话的三个名义 3 秒窗口均为 60 次/秒，P95 约 16.8 ms。

这些结果是受观测代码扰动的 rAF 交付代理指标，不是物理屏幕 FPS、输入延迟、跨机器保证，也不证明某个驱动是唯一原因。对照未改变视口、滚动、overflow 或历史，因此支持在该环境下将大型外层圆角裁剪作为性能触发因素处理。

## 回归

运行 `node scripts/copilot-style-selftest.mjs`。测试执行实际客户端工厂并检查生成的样式，覆盖桌面/移动外层方角、原有尺寸与内层滚动约束、原生输入栏规则保留。该测试不是 GPU 或原生界面集成验收；发布前仍应在目标环境核对历史、输入栏、滚动和原生同会话跳转。

性能调查用的桌面自动化、私有录制、采样器和临时管理扩展不属于产品运行时，不应作为此修复的依赖。部署应保留备份；后续插件升级可能覆盖本地修改，应重新核对上游实现，而非盲目恢复旧版本文件。
